# Contato — Arrighi Advogados & Associados

Página estática (single-page) com o diretório de contatos institucionais da **Arrighi Advogados & Associados**: unidades, telefones, WhatsApp, e-mails e Instagram oficial.

> **Uso corporativo interno.** Página de caráter institucional para colaboradores e parceiros.

## Conteúdo

- Hero com identidade visual oficial da Arrighi (navy `#0E316C` + laranja `#E7984A`).
- Seção **Nossas Unidades**: RJ (Matriz), São Paulo, Campinas, Joinville, Brasília e Salvador — telefones clicáveis (`tel:`) e botão de WhatsApp (`wa.me`).
- Seção **Contato Institucional**: e-mail geral e assessoria de comunicação, com botão de copiar e mailto.
- Instagram oficial: [@arrighiadvogados](https://instagram.com/arrighiadvogados).

## Tecnologia

- HTML + CSS + JavaScript puro (sem build, sem dependências).
- Responsivo (mobile-first), animações de reveal on scroll e microinterações.
- Hospedado via **GitHub Pages** (branch `main`, raiz).

## Estrutura

```
index.html          # página completa
assets/             # logos oficiais da Arrighi (PNG)
```

## Identidade visual

Cores e logos seguem a fonte da verdade oficial da marca (sistema multimarca `brands.js`). **Não alterar a paleta nem recriar logos por descrição.**
